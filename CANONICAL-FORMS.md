# Canonical Forms

NOIR forms are maintained in this repository and submit through the existing NOIR n8n workflow.

- RSVP: `/forms/rsvp`
- Birthday: `/forms/birthday`
- Vendor: `/forms/vendor`
- Tables: `/forms/table_reservation`
- Sponsor: `/forms/sponsor`
- Media: `/forms/influencer`
- Volunteer: `/forms/volunteer`
- Performer: `/forms/artist_music`

Enterprise KHG Forms routes redirect here so NOIR has one intake system.
