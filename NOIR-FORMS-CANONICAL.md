# NOIR Canonical Forms

The canonical NOIR form system lives in this repository and submits through the established NOIR n8n workflow.

Primary visible actions:
- Free RSVP: `/forms/rsvp`
- Birthday: `/forms/birthday`
- Vendor: `/forms/vendor`

Supporting actions:
- Tables: `/forms/table_reservation`
- Sponsor: `/forms/sponsor`
- Media: `/forms/influencer`
- Volunteer: `/forms/volunteer`
- Perform: `/forms/artist_music`

Enterprise KHG Forms URLs redirect here to prevent duplicate intake systems.
