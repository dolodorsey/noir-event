# NOIR Form System

The NOIR website owns its public forms and sends submissions through the established n8n workflow.

Primary public forms:
- `/forms/rsvp`
- `/forms/birthday`
- `/forms/vendor`

Supporting forms:
- `/forms/table_reservation`
- `/forms/sponsor`
- `/forms/influencer`
- `/forms/volunteer`
- `/forms/artist_music`

KHG Forms enterprise routes redirect here so NOIR maintains one canonical intake system.
