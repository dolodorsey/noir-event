# NOIR Direct Form Routing

The canonical NOIR form system lives in this repository and submits through the existing NOIR n8n workflow.

- Free RSVP: `/forms/rsvp`
- Birthday: `/forms/birthday`
- Vendor: `/forms/vendor`
- Table / section: `/forms/table_reservation`
- Sponsor: `/forms/sponsor`
- Media / influencer: `/forms/influencer`
- Volunteer: `/forms/volunteer`
- Performer: `/forms/artist_music`

Enterprise KHG Forms routes redirect here. Do not create a separate NOIR intake table or workflow without a planned migration and reconciliation of historical records.
