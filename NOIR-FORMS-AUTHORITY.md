# NOIR Forms Authority

Canonical NOIR forms remain inside this repository and submit through the existing NOIR n8n workflow.

- Free RSVP: `/forms/rsvp`
- Birthday: `/forms/birthday`
- Vendor: `/forms/vendor`
- Tables: `/forms/table_reservation`
- Sponsorship: `/forms/sponsor`
- Media / influencer: `/forms/influencer`
- Volunteer: `/forms/volunteer`
- Performer: `/forms/artist_music`

Enterprise KHG Forms routes redirect here. Do not create a second NOIR submission pipeline without a documented migration and historical-record reconciliation.
