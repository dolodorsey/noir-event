# NOIR Direct Forms Authority

Canonical NOIR public forms remain inside this repository and submit through the existing NOIR n8n workflow.

Primary visible actions:

- Free RSVP: `/forms/rsvp`
- Celebrate a Birthday: `/forms/birthday`
- Become a Vendor: `/forms/vendor`

Supporting routes:

- Tables: `/forms/table_reservation`
- Sponsorship: `/forms/sponsor`
- Media / influencer: `/forms/influencer`
- Volunteer: `/forms/volunteer`
- Performer: `/forms/artist_music`

The KHG Forms enterprise URLs redirect to these routes. Do not create a second NOIR submission pipeline without an explicit migration plan and record reconciliation.
